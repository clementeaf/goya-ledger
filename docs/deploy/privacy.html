3. What we do NOT store

  • Raw biometric data — only SHA-256 commitments (one-way, irreversible)
  • Private keys — generated and held client-side; never transmitted to Goya
  • Document content — only cryptographic hashes
  • Passwords — authentication via cryptographic key pairs

4. Special category data

Biometric commitments are derived from biometric data (Art. 9 GDPR). We process only the SHA-256 hash — the commitment cannot recover the original biometric data. Processing is based on explicit consent (Art. 9(2)(a)) obtained before biometric capture.

A Data Protection Impact Assessment (DPIA) per Art. 35 GDPR is recommended for deployments processing biometric commitments.

5. Recipients

Personal data may be disclosed to:

  • External identity verification providers — name and national ID transmitted for verification; governed by data processing agreements
  • National supervisory bodies — upon lawful request or as required by eIDAS Art. 19
  • ENISA / national CSIRT — security incident data per NIS2 Art. 23
  • Relying parties — only data the subscriber explicitly consents to present (selective disclosure via SD-JWT)

We do not sell personal data. We do not transfer data outside the EU/EEA without adequate safeguards.

6. Your rights (GDPR Art. 15–22)

  • Access — request a copy of your personal data
  • Rectification — correct inaccurate personal data
  • Erasure — request deletion (subject to legal retention obligations)
  • Restriction — restrict processing in certain circumstances
  • Portability — receive your data in a structured, machine-readable format
  • Object — object to processing based on legitimate interest
  • Withdraw consent — for biometric commitments, at any time without affecting prior processing

Exercise your rights by contacting privacy@goya.cl. We respond within 30 days.

7. Security measures

  • TLS 1.3 with post-quantum hybrid key exchange (X25519 + ML-KEM-768)
  • Tamper-evident audit log with SHA-256 hash chaining
  • Access control via deny-by-default ACL
  • Vulnerability disclosure process per CRA (EU 2024/2847)
  • Incident response per NIS2 Art. 23 (24h/72h notification)

8. Data breach notification

In the event of a personal data breach, we will:

  • Notify the Estonian Data Protection Inspectorate (AKI) within 72 hours (GDPR Art. 33)
  • Notify affected individuals without undue delay if the breach poses high risk (GDPR Art. 34)
  • Notify ENISA / national CSIRT per NIS2 Art. 23 for trust service incidents

9. Supervisory authority

You have the right to lodge a complaint with the Estonian Data Protection Inspectorate (Andmekaitse Inspektsioon): www.aki.ee

10. Changes

We publish changes to this policy at this URL. Material changes are communicated to subscribers via the contact information on file.
